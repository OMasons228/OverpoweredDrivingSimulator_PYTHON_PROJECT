# 🏎️ Overpowered Driving Simulator
Боевой симулятор машинок на питоне, прокачивай тачку, сражайся с другими машинками и стань королем 99 уровня!

## 🎯 В чем польза проекта?
- Для игроков: В первую очередь в развлечении и познании мира машинок на питоне 
- Для разработчиков: Пример того как создавать такого рода игры, изучение кода в игровом характере да и на играх в целом быстрее закрепляется в уме и сразу чувствуешь плоды своего творения
в игре, развлекаясь играя в нее

## Основные графики и данные пользы моей игры
1) Желание сделать свою игру по мере игры в симулятор
2) Польза изучения кода на примере игры (чем она эффективнее нежели проектирование других проектов)
3) Возможная симуляция своих машин на примере 2д игры (для военного характера) и почему это лучше чем преждевременные испытания на реальных событиях

## 🛠️ Основные фичи
  - Гараж: Прокачка автомобиля, его брони пушек патронов колес и многое другое!
  - Битва: Проверка прочности вашей стратегии и боевой машинки на полевых условиях
  - Открытый код: Полезен для изучения разработчикам для создания своих игр

1. Склонируйте репозиторий:
   `git clone https://github.com/OMasons228/OverpoweredDrivingSimulator_PYTHON_PROJECT.git`
